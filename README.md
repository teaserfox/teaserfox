## 🏗️ Мой подход

**Разобраться → спроектировать → реализовать → проверить → улучшить**

Для меня хороший код — это не просто код, который работает.

Это код, который:

* понятно читать;
* удобно тестировать и изменять;
* не страшно передавать другому разработчику;
* можно расширять без постоянной переделки существующей системы.
